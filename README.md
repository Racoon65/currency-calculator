# Калькулятор валют

Пересчёт между швейцарским франком, евро, долларом США, российским рублём и узбекским сумом по официальным курсам центральных банков. Есть график курса за период до 5 лет и сравнение валют.

Приложение работает в браузере на компьютере и телефоне. Его можно установить на главный экран телефона, после этого оно открывается и без интернета на последних сохранённых курсах.

Источник курсов: [Frankfurter](https://frankfurter.dev), резервный источник: [ExchangeRate-API](https://www.exchangerate-api.com).

## Файлы

- `index.html` — само приложение
- `manifest.webmanifest` — описание для установки на телефон
- `sw.js` — сохранение приложения для работы без интернета
- `icon-*.png`, `apple-touch-icon.png` — иконки
